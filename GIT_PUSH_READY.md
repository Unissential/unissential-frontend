## 🔐 HOW TO PUSH

**You need to authenticate. Choose one:**

### Best: GitHub CLI
```bash
# Install: https://cli.github.com/
gh auth login          # Authenticate once
git push origin main   # Then this just works
```

### Good: Personal Access Token
```bash
# Create: https://github.com/settings/tokens (repo scope)
# Then run:
git push https://USERNAME:PAT@github.com/Unissential/unissential-frontend.git main
```

### Secure: SSH Key
```bash
# If already set up:
git push origin main
```

### Easy: Store Credentials
```bash
git config --global credential.helper wincred
git push origin main   # Prompts once, then remembers
```
